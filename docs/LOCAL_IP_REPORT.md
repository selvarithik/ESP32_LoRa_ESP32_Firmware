HMAC authenticates local packets but does not encrypt telemetry. Use a trusted LAN or separately validated HTTPS when confidentiality is needed. A QUEUED peer receipt is a hop acceptance, not durable Gateway storage; PERSISTED is returned only after Gateway commit. Source queues are bounded and volatile, so long outages can reject new packets and reboot can lose in-flight entries. No exactly-once or durable device queue guarantee is made.
